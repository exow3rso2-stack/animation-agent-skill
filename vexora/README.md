# VEXORA — рабочая папка студии

Правила студии (скилл): `plugins/vexora/skills/vexora/` — `SKILL.md` и `bible/`.

- `characters/<name>/approved/` — утверждённые референсы персонажей (класть сюда лучшие результаты тестов T1–T3).
- `pitches/` — концепции.
- `episodes/NN-slug/` — пакеты эпизодов по шаблону `plugins/vexora/skills/vexora/templates/episode.md`.
