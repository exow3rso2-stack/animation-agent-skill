# 05 · Звук и монтаж

## Звуковая архитектура ролика
Три слоя + тишина:
1. **Голос** — рассказчик (английский, глубокий, уверенный, без «диктора новостей»), 2,6–3,4 слова/с; реплики Кипа — коротко, тем же или отдельным голосом.
2. **Подложка** — тёмный кинематографичный эмбиент/пульс (~90–110 BPM), на 14–18 дБ ниже голоса. Нарастает по актам (добавляются слои), убирается перед поворотом.
3. **SFX** — каждое экранное событие звучит. 10–20 событий за 45 с.
4. **Тишина** — оружие. 0,3–0,8 с полной тишины перед главным ударом/поворотом делает удар в 2 раза сильнее.

## Словарь SFX (что ставить на что)
| Событие | Звук |
|---|---|
| Быстрый проезд, whip pan | whoosh (сторона панорамы = стерео-панорама свуша) |
| Удар, приземление, smash zoom | deep bass impact + короткий хвост |
| Поворот сюжета / Vex-Ring | реверс-свуш → тишина → sub-bass drop + glitch tick |
| Нарастание к кульминации | riser 2–4 с, обрывается в тишину или в удар |
| Взрыв | вспышка = transient-щелчок, затем низ + обломки + хвост; тряска синхронна с низом |
| Металл, механизмы | metallic impact, servo, hum |
| Аномалия | glitch, цифровой треск, «высасывание» воздуха |
| Лумо | мягкий высокий гул левитатора, «пиу» при морганиях глаза |
| Локация | эмбиент (вентиляция, капли, ветер, гул города) всегда под всем |

Синхрон: звук удара — точно на кадре контакта (±1 кадр). Свуш начинается за 2–4 кадра до движения.

## Монтаж
- Средняя длина шота 1,5–2,5 с; событие каждые 2–4 с (камера, информация, эффект, эмоция).
- Чередование: серия быстрых склеек (0,6–1,2 с) → короткое замедление (speed ramp до 25–40 %) на главном моменте → снова быстро.
- Переходы по смыслу:
  - **Match cut** — форма/движение продолжается в новом кадре (глаз → планета, кнопка → луна).
  - **Whip pan** — смена места/времени; motion blur + свуш.
  - **Smash zoom / smash cut** — шок, резкая смена громкости.
  - **Flash** — белый/циановый кадр 2–3 кадра на ударе или Vex-Ring.
  - **Glitch** — только для аномалий (фирменный, не злоупотреблять: ≤3 на ролик).
  - **Speed ramp** — разгон в действие / торможение на ударе.
  - **Motion blur transition** — связка быстрых движений одной стороны.
  - **Cinematic cut** — простая склейка по действию; это 70 % склеек.
- Финальный кадр рифмуется с первым (луп) — зритель пересматривает.
- Без интро, логотипа и «подпишись» в начале. Брендинг = Vex-Ring и стиль.

## Титры
1–3 слова, смена по началу слова, жирный гротеск, белый + тёмная обводка и тень, базовая линия ≈72 % высоты; ключевое слово фразы — Anomaly Cyan (одно на фразу, не каждое).

## Экспорт
1080×1920, 30 или 60 к/с (единообразно для канала), H.264 High, yuv420p, bt709, AAC 48 кГц 320 кбит/с, громкость −14 LUFS, true peak ≤ −1 dBTP. Проверка — модуль `reel-export` скилла `shorts-animation`.
