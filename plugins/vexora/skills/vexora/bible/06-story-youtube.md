# 06 · История, удержание, YouTube

## Где искать идеи
Научные парадоксы · невероятные эксперименты · странные гипотезы · реальные необъяснимые явления · «что, если» с неочевидным последствием · интеллектуальные ловушки · бытовой предмет, который нарушает один закон физики.
Фильтр: если зритель угадывает финал по названию — идея не годится.
Перенасыщено (ноябрь 2026, по исследованию канала): космос/катастрофы «What if», «day by day / hour by hour», MSA-истории от первого лица, Bright Side-загадки. Брать из этих зон можно только с действительно новым поворотом.

## Структура Short (гибкая)
| Время | Задача |
|---|---|
| 0–2 с | HOOK: невозможное событие уже происходит на экране + первая фраза-парадокс |
| 2–7 с | Правило мира/эксперимента понятно, главный вопрос открыт |
| 7–20 с | Нарастание: 2–3 шага, каждый страннее и опаснее |
| 20–35 с | Осложнение: правило ломается/последствие бьёт по герою |
| финал | Развязка показом, затем поворот, который меняет смысл начала; последний кадр рифмуется с первым |
~2,6–3,4 слова/с: 30 с ≈ 85–100 слов, 45 с ≈ 120–150, 60 с ≈ 160–200.

## Удержание
- Событие каждые 2–4 с; ни одной «объясняющей» сцены без движения.
- Держать открытым минимум один вопрос до последней секунды.
- Никаких кадров, похожих на концовку, до концовки.
- Поворот подготовлен: зритель при пересмотре должен найти подсказку в первых секундах (это повышает пересмотры).

## YouTube-пакет (на каждый ролик)
1. 5 заголовков + лучший с объяснением. Правила: до ~50 знаков, интрига без лжи, «You»/конкретика/число, КАПС ≤1 слово, ролик выполняет обещание.
2. Первый кадр (он же превью в ленте Shorts): самый сильный визуальный момент, читается на телефоне за 0,5 с.
3. Превью (если нужно): один объект, момент «за секунду до», 0–3 слова, не повторяющие заголовок.
4. Описание: 1–2 предложения-интрига + вопрос зрителю + ссылка на связанный ролик.
5. Хештеги: 3–5 (#shorts + тема + формат).
6. Ключевые слова: 8–15.

## Монетизация
Свой герой и мир, свой сюжет и развязка в каждом ролике, реальная анимация и монтаж, авторская правка — это отличает VEXORA от шаблонного ИИ-контента. Жутко — да, кроваво — нет.
