# 07 · Контроль качества

Проверять на трёх уровнях: каждая сгенерированная картинка → каждый анимированный шот → весь ролик. Результат — таблица «шот · проблема · исправление · статус» в LOG эпизода.

## Картинка (до анимации)
| Проверка | Типовая проблема → исправление |
|---|---|
| Анатомия | лишние/слипшиеся пальцы → inpaint руки, или руку в карман/за предмет, или кадр крупнее |
| Идентичность | пропала прядь/гогглы, другой цвет куртки → регенерация с референсом + якорь дословно; Flux-редактирование утверждённого кадра |
| Стиль | слишком фотореалистично / плоско → поднять вес style-reference T3, добавить негатив |
| Окружение | пустой фон → добавить передний план и 2 живые детали в промпт |
| Тени и свет | персонаж «наклеен», нет контактной тени, свет с разных сторон → указать направление ключа, «soft contact shadow under feet» |
| Палитра | нет «холодный мир — тёплый герой» → переписать блок Lighting/Palette |
| Артефакты | каша в мелких деталях, кривой текст → upscale + inpaint, текст в монтаже |
| Композиция 9:16 | важное в зоне титров/кнопок → reframe или outpaint |

## Анимированный шот
- Лицо и одежда не «плывут» (сравнить первый и последний кадр с референсом).
- Нет морфинга рук и ног, нет «скольжения» стоп по полу.
- Движение с весом и инерцией, не роботизировано, есть вторичное движение.
- Камера делает одно понятное движение.
- Фон не «дышит» и не меняет архитектуру.
→ Исправление: обрезать до чистого фрагмента; меньше амплитуды; start+end frame; другой сид; другой генератор.

## Весь ролик
- [ ] Хук в 0–2 с: невозможное уже на экране.
- [ ] Событие каждые 2–4 с (пройти по таймлайну и отметить).
- [ ] Персонажи одинаковые во всех шотах (контактный лист рядом).
- [ ] Единый стиль и логика палитры по актам.
- [ ] Эффекты не перегружают кадр; у каждого есть причина.
- [ ] Звук и картинка синхронны (удары ±1 кадр), нет «немых» важных моментов.
- [ ] Есть тишина перед главным ударом.
- [ ] Сильная, неочевидная концовка; последний кадр рифмуется с первым.
- [ ] Титры не перекрывают лица и не попадают под кнопки.
- [ ] −14 LUFS, 1080×1920, ffprobe-проверка.
- [ ] Заголовок/превью обещают то, что ролик выполняет.
